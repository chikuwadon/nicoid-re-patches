# v1.8.4 validation record

Date: 2026-10-13 (Japan)
Status: local pre-release review; no v1.8.4 release published.

## Scope

The review covers existing feature areas as well as recent changes: startup and settings,
normal/Shorts/popup/background playback, gestures and comment timing, watch history,
creator/channel lists, local playlists and selection, filtering, authentication,
network/image caches, Cast, explicit-folder video storage, and the build/payload merge path.
All 114 Java helper sources compile against the Android API. Native and smali integration
checks use the merged application/helper DEX containing 8,016 original application classes.
This is a cross-feature source and integration review, not proof of every Android execution path.

## Confirmed findings and changes

| Finding | Change | Evidence |
| --- | --- | --- |
| Cache-root reads repeatedly rewrite the same persisted folder bookmark | Write only when the bookmark is missing or differs | 100 repeated root reads produce no additional preference writes |
| Video filename matching recompiles its regular expression per call | Reuse one compiled pattern | Storage, metadata and ownership tests pass |
| A retained legacy comment file can trigger recompression of an already valid compressed copy | Remove the duplicate without rewriting the compressed copy; fall back to legacy data if gzip is corrupt | Preserved timestamp and corrupt-gzip recovery checks pass |
| Search filtering decodes the same URL and parses boundaries for every video | Use an eight-entry cache of immutable compiled bounds, with per-thread date parsing | Inclusive/exclusive boundaries, invalid input, eviction and 2,000 concurrent matches pass |
| Search UI creates adapters for spinners immediately replaced by range buttons | Remove the unused adapter construction | Search range/date boundary tests and compilation pass |
| Typed backup import silently coerces fractional/string/overflow values into integer settings | Validate exact integral values and numeric types before import | Round-trip and malformed numeric import tests pass |
| Pending comment-history jobs strongly retain their weak-map player key and can issue another request after closing during a delay | Store a weak owner reference, check closed state and recheck after the delay | Released/closed/changed player tests issue no extra requests |
| Legacy smali can mask the revised comment-history Java implementation during DEX merging | Remove the obsolete class-family override and guard eight canonical Java families in CI | Source-precedence guard and rebuilt DEX checks pass |

The previously requested advertising purchase row removal is retained. The compiled settings
payload contains the version row and excludes the purchase row; the manifest does not register
the purchase screen or billing permission.

## Validation completed

- Thirty existing/new JVM suites cover playback policies, Shorts gestures, themes, creator data,
  cache row data, settings backups, content/history rules, request headers, dialog colors,
  manual cookies, gesture rules, video counters, data models, search bounds/ranges/date presets,
  playback routing, pagination, NG comments, posting rules, translations, transfer planning,
  storage checks, memory/disk/network cache policies and comment-history cancellation.

  reuse, popup geometry (10,000 randomized cases) and event routing, playback return, Cast relay
  concurrency/teardown, and restoration of the settings version row.
- Storage fixtures pass for folder-first acquisition, unselected list behavior, picker cancellation,
  compressed comments, packed stream boundaries, loopback HTTP range playback, cached artwork,
  and private history/bookmark routing. Artwork fixtures model an explicitly selected provider root;
  they do not claim to reproduce Android's SAF implementation.
- Player timing/container and HLS URL compatibility tests pass.
- Final merged DEX checks pass: 45 injected-call argument checks, 10 folder-first lifecycle paths,
  12 HLS routing paths, 99 cache constructors and 88 playback URI hooks, 26 playback contracts,
  bulk-selection contracts, video information counters, comment commands, dock/cache contracts,
  and shared information/theme/layout integration contracts.
- Shorts/menu/cookie integration checks pass for 287 helper references after updating the checker
  to follow the existing PlayerGestures-to-Shorts reflection route.
- Java compilation, D8 generation, smali assembly and native/helper DEX merging pass.
- Compiled manifest/settings validation and whitespace checks pass.

## Test infrastructure corrections

The loopback playback test now compiles its PlaybackUrls dependency. The artwork fixture no
longer assumes implicit private video storage. The private-storage test accepts explicit tool
and helper paths instead of a removed scratch directory. The Shorts DEX checker follows the
current gesture dispatch route instead of requiring the superseded direct call.

Some standalone DEX checkers use Morphe's relocated dexlib package. For local execution with
the available org.jf dexlib, imports were adapted only in temporary copies; repository imports
remain compatible with the intended Morphe dependency.

## Remaining release gates

- Apply the actual rebuilt Morphe patch to the supported original 6.49 APK and run final APK
  checks. The merged review DEX precedes Kotlin patch-time hooks. In particular,
  PaidHooksDexTest cannot pass on that intermediate DEX because paid-label binding is inserted
  by NicoidModPatch at patch application time. This is an uncompleted final-APK check, not a
  claimed successful test. A separate dialog checker invocation also needs its full input pair.
- Run the complete Gradle/Morphe build in the release environment; the local validation above
  compiles and assembles helpers/payloads, not the complete distribution pipeline.
- Device checks remain necessary for Android startup, SAF folder permissions and SD-card provider
  behavior, acquisition/copy/pause/reuse with many cached videos, online playback and comment APIs,
  rotation/background lifecycle, popup gestures and theme rendering.
- Storage-provider latency with large folders and frame/memory behavior on real devices have not
  been benchmarked. No measured speedup or blanket absence of defects is claimed.

Public v1.8.3 assets, release notes and CHANGELOG remain unchanged by this review.
