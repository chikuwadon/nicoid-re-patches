## Implemented audit findings

| Finding | Implemented change | Validation |
| --- | --- | --- |
| F1: comment replacement loses the previous copy on failure | Serialized video ownership, unique temporary files, backup/read fallback and interrupted-swap recovery; orphan/old partial cleanup | Installation, write and rollback failures; interrupted recovery; 100 concurrent saves |
| F2: implicit HLS ranges collapse in size planning | Resolve effective offsets, reject invalid ranges and protect total-size arithmetic | Three 100-byte ranges total 300; existing audio/video/variant cases and malformed ranges |
| F3: malformed playlists cause unchecked UI failures | Validate snapshot/entry types and identities; preserve stored data and show read failure/retry; refuse invalid writes | Invalid arrays/entries/references, concurrent edits and failed-storage rollback |
| F4: duration fields and slider disagree | Shared range model, guarded two-way field updates, disabled invalid input state and explicit unlimited control | Mixed typed/dragged model sequence, preset/date/search suites, packaged UI wiring |
| F5: single-file SAF lookups scan every video directory | Root/directory snapshots, scoped locks and metadata reuse; mutation invalidation on stream close | 1,000-directory fixture reads only root and target; expiry, writes, legacy flat files and independent slow/fast providers |
| F6: selection rebuilds playlists and blocking writes run on UI | Retain ListView/adapter for selection, recycle compatible row types, update footer/count, serialize writes on worker | Concurrent transactions, malformed-store preservation, no-render selection hook in packaged DEX |
| F7: every thumbnail write scans/sorts the directory | Incremental size/age index with periodic/startup reconciliation and bounded eviction | Repeated-write scan count, restart reconciliation, expiry and 32 MiB bound |
| F8: source tests can miss overridden shipped code | Explicit ownership for all 117 Java families; hash acknowledgements for 42 smali families; Gradle/CI guard and actual merged-payload verifier | Unacknowledged shadowed edit rejected; 14 merged/packaged integration checks |

Two smali override families were reconciled with their Java sources and removed:
CacheOutputStream and ImageDiskCache. Their original constructors/public APIs remain
available. Source-only changes are now checked against the implementation-owner manifest.

1. Acquire, list, play, seek, pause/resume and delete cache videos in the selected folder;
   repeat with several videos and an SD-card provider where available.
2. Alternate typing duration values, dragging handles, selecting presets and toggling
   unlimited. Confirm both displayed values and actual search results agree.
3. In a long local playlist, scroll then enter multiple selection; select/clear/all/done,
   move/delete items, create/delete folders and verify data after restart. Selection changes
   should preserve the list and scroll position.
4. Confirm thumbnail display while scrolling/reopening lists, and normal/Shorts/popup
   playback plus theme rendering. Fault injection and damaged-store testing are already
   automated; deliberately corrupting user data is not required for routine device testing.
