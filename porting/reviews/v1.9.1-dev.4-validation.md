# v1.9.1-dev.4 flat UI and icon refresh

Base: the corrected v1.9.1-dev.3 bundle. Its manifest is retained byte-for-byte; native method delta, patch executor behavior and input hashes are unchanged.

Tag list: PlayerTheme styles only the existing taglist and its individual tag children. Flat rectangular per-item RippleDrawables use nicoid_tag_item_dark (#ff24262b) and nicoid_tag_item_light (#fff0f0f0), with the shared NicoidFlatTag depth style. The parent has no panel fill, and a 4 dp bottom margin separates each item except the last. Existing row dimensions, text size, padding and click/long-click handlers remain intact. Uploader dark backgrounds remain #292b31 and light uploader backgrounds remain unchanged.

Global depth policy: FlatUi191 removes decorative outlines/text shadows and background gradients from activity/dialog UI. Controls in non-overlapping LinearLayouts use zero Z/elevation. Other views retain sibling ordering while their outline shadow alpha is zero. Existing corner outlines are delegated and retain clipping geometry. Generated playlist/action popups have zero window elevation; popup themes request zero elevation. Framework and Material button depth, compatibility background shadows and legacy Holo nine-patch button skins are flattened while retaining padding and minimum size. XML loading/status text shadows are removed.

Exceptions: original thumbnail/image/video/WebView pixels are never recolored. Video/comment rendering and explicitly marked media-overlay text/gradient readability effects remain. Drag/transient state and overlapping/FAB/drawer Z ordering remain; retained Z is not a visible decorative shadow. Standard dependency-owned animated indicators, progress/seek assets, service/brand logos and notification/cast content are retained when replacement could change their functional layout or state behavior.

UI asset audit: 306 raster drawable names across 785 files were inventoried. 28 app UI glyph names (37 density variants) were refreshed as theme-aware toolbar or white media/command vectors. Every prior resource name/configuration and intrinsic width/height was preserved, including literal pixel units for nodpi assets. No View layout, ImageView scale type or resource ID is changed. The audited vector definitions and repeatable replacement step live in porting/theme-191/flat-icons.json and refresh-icons.py.

Refreshed glyphs: combig, commedium, commentoff, commenton, commentpost, comnaka, comshita, comsmall, comue, dicoff, dicon, fullscreen, ic_drawer, ic_menu_recent_history, ic_menu_search, ic_menu_share, info, lock, menubutton, next, normalscreen, pause, play, popup, prev, repeatoff, repeaton, unlock.
